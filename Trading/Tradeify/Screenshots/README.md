# Trade Screenshots

Drop chart screenshots here. Naming: `YYYY-MM-DD-MNQ-note.png` (e.g. `2026-07-08-MNQ-orb-long.png`).

These sync via git. In a Claude Code session, Claude can open and analyze them:
- Was this genuinely an A+ setup, or a B I talked myself into?
- Was the stop where the playbook says? Right size?
- Did the +2R target / structure target make sense?

**The review loop:** screenshot on Mac → Obsidian Git pushes → Claude pulls on the VPS → reads the chart → tells me the truth.
